# Rhino Sync — user manual

Rhino Sync is a live two-way link between Rhino 8 and QGIS through a shared folder: draw in Rhino, see it in QGIS; send QGIS layers, with their symbology, back to Rhino.

**Read the manual:** https://raduandrei-source.github.io/RhinoSync/ (English; Romanian from the language switch).

This repository holds only the manual, a single web page generated from the Markdown sections of the project (sections, literature, changelog). The plugin itself is distributed separately. The manual of [MapQuilt](https://raduandrei-source.github.io/MapQuilt/) is in its own repository.
